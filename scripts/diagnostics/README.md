# Разовые проверки источников

Скрипты этой папки не входят в основной пайплайн: `run_all.sh` их не запускает.
Они отвечали на вопросы перед написанием сборщиков, а их выводы зафиксированы
в `PROTOCOL.md` (раздел 12) и в `results/metrics/`.

| Скрипт | Вопрос | Ответ (01.10.2026) |
| --- | --- | --- |
| `probe_ru_sites.py` | Какие русскоязычные сайты доступны и дают время публикации с минутами | ForkLog, Bits.Media — да; RBC Crypto — код 401; Profinvestment — справочные карточки вместо новостей |
| `check_archive_depth.py` | С какого года реально доступны публикации | ForkLog — с 2014-09, Bits.Media — с 2017-08 |
| `probe_bulk_access.py` | Можно ли собирать заголовки пачками | ForkLog — программный интерфейс WordPress; Bits.Media — нет |
| `inspect_sources.py` | Как устроены ответы интерфейса и лента | ForkLog: 20 записей за запрос, отбор по датам игнорируется |
| `inspect_pagination.py` | Работает ли постраничный обход | ForkLog — да; Bits.Media — номер страницы игнорируется |

Запуск: `python scripts/diagnostics/<имя>.py`
