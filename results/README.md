# Результаты

Всё в этой папке создаётся кодом.

| Путь | Что внутри | В git |
| --- | --- | --- |
| `env/` | манифест окружения и `requirements-lock.txt` | да |
| `splits.json` | точные даты выборки, фолдов и окна настройки | да |
| `predictions/` | прогнозы каждой модели по фолдам и зёрнам | нет (архив в Zenodo) |
| `metrics/` | метрики и результаты тестов | да |
| `tables/` | таблицы для статьи | да |
| `figures/` | рисунки для статьи | да |
