# Результаты

Всё в этой папке создаётся кодом. В git результаты не хранятся: в Colab папка лежит на Google Диске
(путь задаёт переменная `CRYPTONEWS_RESULTS_DIR`), а результаты, по которым написана статья, архивируются
вместе с релизом кода в Zenodo.

| Путь | Что внутри | Шаг |
| --- | --- | --- |
| `env/` | манифест окружения и точные версии пакетов (`requirements-lock.txt`) | 0 |
| `metrics/` | отчёты шагов в JSON: границы выборки, покрытие данных, выбор модели тональности, итоги оценки; в каждом — манифест запуска (время, коммит, версии пакетов, хеши конфигурации и входных файлов) | 1–8в |
| `tables/` | промежуточные таблицы в CSV: этапы очистки новостей, метрики, тесты, бэктест, тест Грейнджера | 3–8в |
| `annotation/` | файлы Excel для ручной разметки (готовая разметка — в `annotation/labels/` репозитория) | 5 |
| `splits.json` | точные даты выборки, окна настройки и тестовых фолдов | 6 |
| `predictions/` | прогнозы каждой модели по фолдам и зёрнам, выбор гиперпараметров на окне настройки (`tuning.json`) | 7 |
| `report/`, `report.zip` | таблицы статьи и приложения (`tables.xlsx`), рисунки статьи, версии пакетов | 9 |
