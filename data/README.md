# Данные

Сырые данные в git не хранятся. Их скачивают и готовят скрипты из `scripts/`; сюда они попадают автоматически.
В Colab эта папка лежит на Google Drive, путь задаётся переменной `CRYPTONEWS_DATA_DIR`.

| Папка | Что внутри | Откуда |
| --- | --- | --- |
| `raw/binance/` | часовые свечи BTCUSDT и ETHUSDT | `01_download_prices.py`, публичный API Binance |
| `raw/cryptovision/` | архив CryptoVision | `02_prepare_news_en.py`, Mendeley Data, DOI 10.17632/3c3xtxtfb6 |
| `raw/ru_news/` | метаданные русскоязычных новостей и сырые страницы | `03_scrape_news_ru.py` |
| `interim/` | очищенные таблицы новостей и цен в UTC | шаги 02–05 |
| `processed/` | итоговые признаки и целевая переменная по каждому активу | шаг 06 |

Правила:

- файлы в `raw/` вручную не редактируются: любые изменения делает код;
- для каждого скачанного файла в манифест пишется хеш SHA-256;
- лицензии источников нужно проверить и вписать сюда до публикации (задача 10.3):
  - CryptoVision — лицензия со страницы набора на Mendeley Data;
  - русскоязычные сайты — условия использования; публикуются только метаданные (заголовок, URL, время).
