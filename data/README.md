# Данные

Данные в git не хранятся. Их скачивают и готовят скрипты из `scripts/`, сюда они попадают автоматически.
В Colab эта папка лежит на Google Диске, путь задаёт переменная `CRYPTONEWS_DATA_DIR`.

| Папка | Что внутри | Откуда |
| --- | --- | --- |
| `raw/binance/` | часовые свечи BTCUSDT и ETHUSDT на полной сетке UTC; кэш месячных архивов, в том числе 15-минутных свечей для сверки часового пояса CryptoVision | `01_download_prices.py`: месячные архивы data.binance.vision, контрольные суммы SHA-256 сверяются при скачивании |
| `raw/cryptovision/` | архив набора CryptoVision, версия 2 | кладётся вручную: кнопка «Download All» на странице https://data.mendeley.com/datasets/3c3xtxtfb6/2 (Mendeley отклоняет автоматическое скачивание) |
| `raw/ru_news/` | метаданные материалов ForkLog: идентификатор, адрес, заголовок, время публикации (`date_gmt`, UTC) | `02_collect_forklog.py`: программный интерфейс сайта (WordPress REST API), не чаще одного запроса в секунду |
| `interim/` | очищенные новости (`news_en.parquet`, `news_ru.parquet`) и вероятности классов тональности по каждой модели-кандидату (`sentiment/`) | шаги 3–5 |
| `processed/` | признаки и целевая переменная по каждому активу | шаг 6 |

Правила:

- файлы в `raw/` вручную не редактируются: любые изменения делает код;
- для каждого скачанного или положенного вручную файла в манифест запуска пишется хеш SHA-256.

## Источники и условия использования

- **Цены.** Публичные архивы исторических данных Binance (https://data.binance.vision). В репозиторий и архив релиза свечи не копируются: скрипт шага 1 скачивает их заново и сверяет контрольные суммы.
- **Англоязычные новости.** Mashrafi A. S. et al. CryptoVision: A comprehensive dataset for crypto news and trend prediction. Версия 2. Mendeley Data, 2025. DOI: [10.17632/3c3xtxtfb6.2](https://doi.org/10.17632/3c3xtxtfb6.2). Лицензия CC BY 4.0. Набор не перераспределяется: его скачивают со страницы набора.
- **Русскоязычные новости.** Онлайн-журнал ForkLog (https://forklog.com), снимок от 01.10.2026, 56 383 материала. Пользовательское соглашение сайта (редакция от 01.06.2020) запрещает копирование материалов без письменного согласия редакции. Поэтому в архив релиза входят только идентификаторы материалов, адреса, время публикации и рассчитанные оценки тональности; заголовки скрипт шага 2 собирает заново. Исключение — 400 заголовков в файлах ручной разметки (`annotation/labels/ru_annotator*.csv`): они приводятся со ссылкой на источник как материал научного исследования, по ним проверяются модели тональности.
