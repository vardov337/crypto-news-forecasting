# Ручная разметка тональности (этап 5)

Разметка нужна, чтобы проверить модели тональности на наших заголовках и выбрать для признаков лучшую из кандидатов (PROTOCOL.md, раздел 5).

- `instruction.md` — инструкция для разметчиков (задача 5.1). Тот же текст стоит на первом листе файлов разметки.
- Файлы для разметчиков готовит шаг 5 (`scripts/05_sentiment.py`) в папке результатов `annotation/`:
  - `annotation_<язык>_main.xlsx` — 400 заголовков для первого разметчика; выборка стратифицирована по годам и источникам, объём страты пропорционален числу новостей в ней (задачи 5.2–5.3);
  - `annotation_<язык>_second.xlsx` — 100 из этих 400 заголовков для независимого второго разметчика (задача 5.4).
  Разметчик видит только номер и заголовок. Адрес, дата и источник лежат на скрытом листе `_key`.
- `labels/` — готовая разметка, по файлу на язык и разметчика: `en_annotator1.csv`, `en_annotator2.csv`, `ru_annotator1.csv`, `ru_annotator2.csv`. Колонки: `id`, `url`, `title`, `label`, `comment`.

Метки: `positive`, `neutral`, `negative` — ожидаемое влияние новости на цену с точки зрения инвестора, по одному заголовку.

Проверку моделей и выбор модели делает шаг 5b (`scripts/05b_choose_sentiment.py`): согласие разметчиков (каппа Коэна), accuracy, macro-F1 и F1 по классам с бутстреп-интервалами. Выбирается кандидат с наибольшим macro-F1 на разметке первого разметчика; правило зафиксировано до разметки.
