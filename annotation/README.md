# Ручная разметка тональности (этап 5)

- `instruction.md` — инструкция для разметчиков (задача 5.1);
- `en_sample.csv`, `ru_sample.csv` — выборки по 400 заголовков, стратифицированные по годам и источникам (задачи 5.2–5.3);
- `second_annotator.csv` — независимая разметка 100 заголовков (задача 5.4).

Метки: `positive`, `neutral`, `negative` — с точки зрения ожидаемого влияния на цену актива.
