## Что внутри

| Путь | Что это |
| --- | --- |
| `results/report/` | таблицы статьи и приложения (`tables.xlsx`: Т1–Т5, П1–П12), рисунки статьи (PNG и SVG), точные версии пакетов |
| `results/predictions_combined_<актив>.parquet` | факт и прогнозы всех 18 вариантов моделей (среднее по зёрнам) на общих часах теста; по ним считаются все метрики, тесты и стратегии |
| `results/predictions/<актив>/<модель>/tuning.json` | подбор гиперпараметров на окне настройки |
| `results/tables/`, `results/metrics/` | промежуточные таблицы и отчёты шагов 1–8г с манифестами запусков |
| `results/splits.json`, `results/env/` | точные даты окон проверки; окружение расчётов |
| `data/interim/news_<язык>.parquet` | метаданные новостей без заголовков: время публикации (UTC), адрес, источник, упоминания монет |
| `data/interim/sentiment/<язык>/` | вероятности классов тональности: у выбранной модели — для всех новостей, у остальных кандидатов — для размеченных заголовков |

Заголовки новостей не включены: пользовательское соглашение ForkLog запрещает копирование материалов
без согласия редакции, а набор CryptoVision доступен по DOI 10.17632/3c3xtxtfb6.2 (см. `data/README.md`).

## Как пользоваться

- Проверить числа статьи без расчёта: метрики и тесты пересчитываются по
  `predictions_combined_<актив>.parquet`; таблицы статьи — в `results/report/tables.xlsx`.
- Повторить шаги 5b–9 без сбора новостей и расчёта тональности: задать
  `CRYPTONEWS_DATA_DIR=release/data` и `CRYPTONEWS_RESULTS_DIR=release/results` (или скопировать папки),
  скачать цены шагом 1 и запустить шаги по порядку; шагу 7 нужна видеокарта.
