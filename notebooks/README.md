# Ноутбуки

[![Открыть в Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/vardov337/crypto-news-forecasting/blob/main/notebooks/colab.ipynb)

`colab.ipynb` — запуск пайплайна в Google Colab: подключение Google Диска для данных и результатов,
установка свежей версии кода и по одной ячейке на каждый шаг из `scripts/`.

Ноутбук только запускает скрипты. Числа, таблицы и рисунки для статьи получаются в самих скриптах,
поэтому результат не зависит от порядка выполнения ячеек.
